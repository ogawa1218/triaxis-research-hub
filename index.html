01 / AXIS

VO2MAX 向上

最大酸素摂取量はパフォーマンスの天井であると同時に、全死因死亡の強い予測因子でもある。 処方 / 量 / 測定 / 耐久性 / 健康寿命 のジャンルに分けて整理する。

▸ PRACTICE — 明日から回せる形

  1. 週1本の4×4（4分×4本／90〜95%HRmax、レスト3分）を「VO2max刺激枠」として固定する。増やさない。
  2. 残りは低強度で距離を積む。データ上、走行距離とVO2maxの関係にプラトーは観測されていない。
  3. ウォッチのVO2max推定値は絶対値ではなく、同一デバイス内のトレンドとしてのみ読む。
  4. 疲労下の指標（90分走後のペース維持率）を月1で測る。フレッシュな数値だけを追わない。
02 / AXIS

睡眠

睡眠は回復手段ではなく、トレーニング適応そのものを成立させる前提条件。 パフォーマンス / メカニズム / 概日リズム / 計測 のジャンルで見る。

▸ PRACTICE — 明日から回せる形

  1. 「7時間」を下限ラインとして固定。それ以下が続く週は、強度練を1本削る判断に直結させる。
  2. レース1週間前は就寝を55〜60分前倒し。当日だけ早く寝ても効果は薄い。
  3. 寝室17〜19℃。深部体温が約1℃下がることが入眠のスイッチになる。
  4. 夜練の日は終了後の光曝露と刺激を落とす。クロノタイプに合わない時刻設計は適応を削る。
03 / AXIS

腸活

腸内環境はエネルギー基質・バリア機能・免疫・全身の炎症レベルを決める変数。 運動×腸 / バリア機能 / レース補給 / 次世代成分 / 食事設計 に分ける。

▸ PRACTICE — 明日から回せる形

  1. ロング走を補給の練習として使う。60 → 75 → 90 g/h と段階的に上げ、いきなり120g/hを狙わない。
  2. 60g/hを超える日はグルコース：フルクトース＝1:0.8前後のブレンドを選ぶ。
  3. 食物繊維は多様性で摂る。効果は一過性で、練習と同じく止めれば戻る。
  4. 減量期・移動期はバリア機能が落ちやすい局面。この時期に補給の新規実験を持ち込まない。
04 / CORE

交差点

このサイトの本題。3軸は独立していない。腸内細菌は睡眠を、睡眠はトレーニング適応を、 トレーニングは腸内細菌を動かす。現時点で言えることと言えないことを分けて置く。

GUT × SLEEP

最もエビデンスが厚い重なり。ただし「主観的睡眠は改善、客観指標は不確実」という非対称が繰り返し報告されている。

GUT × VO2MAX

短鎖脂肪酸と乳酸代謝を介した経路。機序は魅力的だが、ヒトでの因果はまだ弱い。期待値の置き方に注意が要る領域。

SLEEP × VO2MAX

睡眠不足はVO2maxそのものより「疲労下で数粋を守る力」を削る可能性。デュラビリティと接続して考える。

▸ PRACTICE — 3軸を1つのループにする

  1. 週の起点を睡眠に置く。睡眠が崩れた週は、強度ではなく量を残す（適応が乗らないため）。
  2. 高強度期は腸のバリアが緩みやすい局面。同じ週に補給の新規実験を重ねない。
  3. プロバイオティクスは睡眠の質目的なら期待値小〜中、消化器症状の予防目的なら現実的。目的を分けて使う。
  4. 3つとも効果は一過性で可逆。単発の介入ではなく、止めない仕組みを設計する。
